# Module: air

**Role:** Pure-data model for MUGEN/Ikemen GO animation (`.air`) files — the read-path vocabulary a library consumer (editor, engine) works with. No parsing, file I/O, or write-only (format-preservation) logic yet.
**Files:** `air/animation.go`
**Exports:** `Animation` (struct), `Frame` (struct), `ClsnBox` (struct), `Flip` (string type) with constants `FlipNone`, `FlipH`, `FlipV`, `FlipHV`, `BlendMode` (string type)
**Depends on:** none
