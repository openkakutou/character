# Module: air

**Role:** Read and write paths for MUGEN/Ikemen GO animation (`.air`) files. `animation.go` is the pure-data vocabulary a library consumer (editor, engine) works with. `parser.go` turns `.air` text into that model, covering the format's happy path and hardening against malformed/unusual input — comment lines (`;`, whole-line or trailing) are ignored, an empty file yields an explicit empty result, and a malformed action header, a frame line with missing/non-numeric/negative group-or-image fields, or a reader failure returns a descriptive, line-numbered error rather than panicking or producing incorrect data. `serializer.go` is the inverse: it writes an `[]Animation` back out as valid `.air` text that `Parse` reads back into an equivalent structure, but always as fresh text — Clsn boxes are always emitted per frame (never reconstructed as a `Clsn1Default`/`Clsn2Default`, since `Frame` only stores already-resolved boxes), and a `Loopstart` marker is written only when `LoopStart` is non-zero. `document.go` covers the format-preserving case `Parse`/`Serialize` don't: `ParseDocument` decodes `.air` text the same way `Parse` does while also retaining the original source bytes, and `Document.Serialize` writes those retained bytes back out verbatim — so a round trip on unmodified content reproduces the source file byte-for-byte, comments included. Mutating `Document.Animations` has no effect on `Serialize`'s output (see `.vibe/decisions/003-air-round-trip-via-separate-document-type.md`). `resolve.go` adds `SpriteResolver`, the package's first cross-package integration point: it indexes a `[]sff.SpriteGroup` by `(Group, Image)` once, so `Resolve` can look up any `Frame`'s `sff.Sprite` without rescanning the whole collection, and returns a descriptive error rather than a zero `Sprite` when a frame references a `(Group, Image)` pair absent from the loaded sprites (see `.vibe/decisions/008-air-sprite-resolution-lives-in-air-package.md`).
**Files:** `air/animation.go`, `air/parser.go`, `air/serializer.go`, `air/document.go`, `air/resolve.go`
**Exports:** `Animation` (struct), `Frame` (struct), `ClsnBox` (struct), `Flip` (string type) with constants `FlipNone`, `FlipH`, `FlipV`, `FlipHV`, `BlendMode` (string type), `Parse(r io.Reader) ([]Animation, error)`, `Serialize(w io.Writer, animations []Animation) error`, `Document` (struct), `ParseDocument(r io.Reader) (*Document, error)`, `(*Document) Serialize(w io.Writer) error`, `SpriteResolver` (struct), `NewSpriteResolver(groups []sff.SpriteGroup) *SpriteResolver`, `(*SpriteResolver) Resolve(frame Frame) (sff.Sprite, error)`
**Depends on:** `modules/sff.md` (via `SpriteResolver`, which resolves `Frame` references against `sff.Sprite`/`sff.SpriteGroup`)
