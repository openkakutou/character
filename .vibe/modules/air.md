# Module: air

**Role:** Read and (first-pass) write paths for MUGEN/Ikemen GO animation (`.air`) files. `animation.go` is the pure-data vocabulary a library consumer (editor, engine) works with. `parser.go` turns `.air` text into that model, covering the format's happy path and hardening against malformed/unusual input — comment lines (`;`, whole-line or trailing) are ignored, an empty file yields an explicit empty result, and a malformed action header, a frame line with missing/non-numeric/negative group-or-image fields, or a reader failure returns a descriptive, line-numbered error rather than panicking or producing incorrect data. `serializer.go` is the inverse: it writes an `[]Animation` back out as valid `.air` text that `Parse` reads back into an equivalent structure. This first pass does not preserve an original file's exact formatting/comments (that byte-exact round-trip is separate, not-yet-implemented future work) — Clsn boxes are always emitted per frame (never reconstructed as a `Clsn1Default`/`Clsn2Default`, since `Frame` only stores already-resolved boxes), and a `Loopstart` marker is written only when `LoopStart` is non-zero.
**Files:** `air/animation.go`, `air/parser.go`, `air/serializer.go`
**Exports:** `Animation` (struct), `Frame` (struct), `ClsnBox` (struct), `Flip` (string type) with constants `FlipNone`, `FlipH`, `FlipV`, `FlipHV`, `BlendMode` (string type), `Parse(r io.Reader) ([]Animation, error)`, `Serialize(w io.Writer, animations []Animation) error`
**Depends on:** none
