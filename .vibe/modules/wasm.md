# Module: wasm

**Role:** `cmd/wasm` is the library's WebAssembly entrypoint: thin `syscall/js` glue exposing the root package's `LoadBytes` (see `modules/root.md`) and the external `github.com/openkakutou/sff` module's `ResolveSpritePixels` to a browser or any JS host as global functions, so a consumer can load a MUGEN/Ikemen character and render its sprites without a Go toolchain of its own. It carries no logic beyond argument conversion, calling into `character`/`sff`, and marshaling results to JS — all real behavior lives in those packages, unit-tested independently.
**Files:** `cmd/wasm/main.go`, `cmd/wasm/smoke.mjs`, `cmd/wasm/testdata/` (its own fixture files for `smoke.mjs`, since the `sff` package's fixtures moved out of this repo with item 035)
**Exports (JS, not Go):**
- `globalThis.OpenKakutouCharacter.load(defBytes, airBytes, sffBytes, cnsBytes)` — four `Uint8Array` arguments, returns `{ character: string|null, error: string|null }` (exactly one non-null)
- `globalThis.OpenKakutouCharacter.resolveSprites(sffBytes, requests, overrideBytes)` — `sffBytes` a `Uint8Array` (transferred once for the whole batch), `requests` an array of `[group, image]` pairs, `overrideBytes` an optional `Uint8Array` (`undefined`/`null` means no override; any other value, including empty, is decoded and its own validation errors apply to every request in the batch); returns one `{ pixels: Uint8Array|null, width, height, error: string|null }` per request, `pixels` a flat row-major straight-alpha RGBA buffer
- `globalThis.OpenKakutouCharacter.saveDef(originalDefBytes, editedInfoJSON)` / `saveAir(originalAirBytes, editedAnimationsJSON)` / `saveCns(originalCnsBytes, editedStateDefsJSON)` / `saveCmd(originalCmdBytes, editedCommandFileJSON)` / `saveZss(originalZssBytes, editedScriptJSON)` (item 039) — each takes that format's own previously loaded `Uint8Array` bytes (empty for a brand new file) plus a JSON string of the current in-memory model (`saveDef`/`saveAir`/`saveCns`'s models match `load`'s own `character`/`animations`/`stateDefs` JSON shapes; `saveCmd`/`saveZss`'s models are independent of `load`'s contract, since `.cmd`/`.zss` aren't wired into `Character`); returns `{ bytes: Uint8Array|null, error: string|null }` — `bytes` byte-exact to the original when nothing really changed, freshly generated valid text otherwise

**Depends on:** root package (`character.LoadBytes`, and `character.SerializeDef`/`SerializeAir`/`SerializeCns`/`SerializeCmd`/`SerializeZss` for the five `save*` globals), the external `github.com/openkakutou/sff` module (`sff.ResolveSpritePixels`, `sff.DecodeExternalPalette` — no longer an in-repo sub-package, see item 035)

**Design decision:** `main.go` is build-tag gated (`//go:build js && wasm`), so it is invisible to a normal host `go build ./...`/`go test ./...` — only `GOOS=js GOARCH=wasm go build ./cmd/wasm` compiles it. Both exposed functions never let an internal panic escape to the JS caller (a `recover()` at each callback boundary reports it as `error` instead — for `resolveSprites`, a panic before results are built falls back to a bare `nil` return rather than a well-formed per-request array, mirroring `load`'s own recovery) and never leave the module in a broken state after an error — the next call is handled independently. `resolveSprites` is batched and stateless — one call resolves many sprites from one `sffBytes` transfer, parsing the file fresh each call rather than keeping Go-side session state across calls — and reports a sprite that doesn't exist with a stable `"sprite not found: "` error prefix, distinguishable from every other failure. See `.vibe/decisions/020-wasm-sprite-pixel-resolution-batched-stateless-contract.md`. `smoke.mjs` is a Node.js verification harness (loads the built `.wasm` via `wasm_exec.js`, the same way a browser would) — it is not a `go test` file since `syscall/js` code cannot run under the plain Go toolchain, and doubles as a minimal JS usage example for both globals. See `.vibe/decisions/019-wasm-entrypoint-byte-buffer-loading-and-json-contract.md` and `docs/wasm.md`. The five `save*` globals (item 039) follow the exact same `recover()`-guarded, never-throws, never-broken-after-an-error shape as `load`/`resolveSprites` — each unmarshals its JSON argument into the corresponding Go model, delegates entirely to the matching root-package `SerializeX` function (see `modules/root.md`), and wraps the result in a shared `saveResult(fileBytes []byte, err error) map[string]any` helper mirroring `result`/`spriteResult`'s existing `{ ..., error }` pattern.
